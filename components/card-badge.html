Website Pribadi Saya

Proyek ini adalah website pribadi yang saya buat sebagai latihan HTML dan CSS di sekolah. Website ini menjadi tempat saya memperkenalkan diri sekaligus menunjukkan hasil belajar saya selama di jurusan TKJ.

Isi website ini terdiri dari beberapa halaman, yaitu halaman profil, kumpulan tombol, kartu proyek, dan bagian tentang saya. Setiap halaman dibuat dengan tujuan melatih satu materi CSS yang berbeda.

Saya memilih warna biru dan krem sebagai warna utama karena terasa tenang dan nyaman dilihat. Kombinasi ini juga membuat teks tetap mudah dibaca di atas latar yang terang.

Setiap halaman memakai cara menulis CSS yang berbeda. Halaman profil memakai CSS inline, halaman tombol memakai CSS internal, dan halaman tentang saya memakai CSS eksternal yang disambungkan lewat tag link.

Di halaman kartu, saya belajar memakai box-sizing supaya lebar elemen sesuai dengan hitungan. Tanpa pengaturan itu, padding dan border akan menambah lebar kartu sehingga ukurannya berbeda dari yang saya tulis di CSS.

Label BARU di pojok kartu memakai position absolute, sedangkan kartunya memakai position relative. Karena itu label selalu menempel di pojok kanan atas kartu, bukan di pojok halaman.

Tombol Ke Atas memakai position fixed, jadi tetap terlihat di pojok kanan bawah layar saat halaman digulir. Saya juga menambahkan z-index supaya tombol tidak tertutup oleh elemen lain.

Selama mengerjakan proyek ini, saya belajar bahwa kesalahan kecil bisa membuat kode tidak berjalan. Contohnya lupa titik koma, lupa tanda pagar pada tautan, atau nama id yang berbeda dengan tujuan tautan.

Karena itu saya selalu mengecek hasilnya di browser dan memakai Inspect Element untuk melihat ukuran serta gaya yang dipakai. Saya juga merapikan kode dengan Prettier supaya mudah dibaca.

Ke depannya saya ingin menambah halaman galeri dan formulir kontak, serta membuat tampilan yang menyesuaikan layar HP. Terima kasih sudah membaca sampai bawah, klik tombol Ke Atas untuk kembali ke bagian paling atas halaman.
